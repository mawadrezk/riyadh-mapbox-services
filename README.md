# 🗺️ خريطة خدمات الرياض - Mapbox

خريطة تفاعلية لمدينة الرياض تعرض **3039 خدمة حقيقية** من OpenStreetMap، باستخدام Mapbox GL JS.

🔗 **رابط المشروع:** [افتح الخريطة من هنا](https://mawadrezk.github.io/riyadh-mapbox-services/)

---

## ✨ المميزات

- عرض **3039 خدمة** حقيقية في الرياض
- فلاتر حسب النوع:
    - 🏥 مستشفيات
    - 🕌 مساجد
    - 💊 صيدليات
    - 🏫 مدارس
- عداد حي للخدمات المعروضة
- واجهة عربية كاملة `RTL` - العربي مش مقلوب
- بحث وفلترة فورية
- خريطة Satellite Streets من Mapbox
- Popup فيه اسم الخدمة ونوعها عند الضغط عليها

## 📊 توزيع الخدمات

| النوع | العدد |
| :--- | :--- |
| مساجد | ~ 1500+ |
| مدارس | ~ 800+ |
| صيدليات | ~ 400+ |
| مستشفيات | ~ 100+ |
| **الإجمالي** | **3039** |

## 🛠️ التقنيات المستخدمة

- **Mapbox GL JS** - عرض الخريطة
- **Mapbox RTL Text Plugin** - إصلاح مشكلة العربي المقلوب
- **GeoJSON** - ملفات البيانات
- **HTML / CSS / JavaScript** - الواجهة
- **OpenStreetMap** - مصدر البيانات الحقيقية
